🧠 How the trick works

This is a mathematical puzzle, not magic. It uses binary numbers (base‑2) to guess your number.

Each of the five grids represents a specific binary place value:

  • Grid 1 → value 16
  • Grid 2 → value 2
  • Grid 3 → value 8
  • Grid 4 → value 1
  • Grid 5 → value 4

Every number from 0 to 31 can be uniquely expressed as a sum of these values. By asking if your number appears in each grid, we determine which values to add together.

For example, the number 25 = 16 + 8 + 1, so it appears in grids 1, 3, and 4, but not in grids 2 and 5.
